## 期末试卷回忆版（2026.01.07）

一共五道大题，无选择，各大题分值从15分至25分不等，均有多个小问，

1. 第一题为对易关系的考察，例如计算 $[\hat{p}^2,x]$（*三维形式*）。有多个小问
2. 第二题为无限深方势阱的变形，变化主要为势阱区域从经典的 $[0,a]$ 变成了 $[a,b]$ ，势阱能量从 $0$ 变成了 $V_0$ 。问了关于求解能量本征值、求得基态能量的概率以及 $\langle x \rangle$
3. 第三题为氢原子的计算，并考虑了电子自旋。给的是 $\frac{\sqrt{3}}{2}\psi_{100}\kai_+ +\frac{1}{2}\psi_{210}\kai_-$ ，要求求解 $L^2 ，S_z$ 的可能值及概率。
4. 第四题为自旋耦合的计算，问自旋为1和 $\frac{1}{2}$ 的粒子耦合后，用非耦合的基态展开的CG系数。
5. 第五题为2-d谐振子，给出的微扰为 $\lambda (x^4 + y^4)$ ，求1，2级能量修正。
